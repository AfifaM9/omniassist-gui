# Nickname Notice

This document records the official nicknames and relationships used for the project.

## OmniAssist is nicknamed **Omni**

The sister agent — the CLI operational, multi-agent engine that plans, calls tools, and
iterates until a task is done — is nicknamed [**Omni**](https://github.com/AfifaM9/omniassist).
Its CLI is exposed through `interfaces/cli.py`.

## OmniAssist GUI is nicknamed **GUI Omni**

The graphical, browser-based front end for OmniAssist is nicknamed **GUI Omni**.

## Usage

- Write the full name on first mention in formal documentation, then the nickname.
- The nickname is a shorthand, not a product or package rename. Repository names,
  module names, and package identifiers keep their existing names.
- The nicknames are reflected in the web UI, where the execution inspector is
  labelled **Omni's Computer** and the tool inspector is labelled **Omni's MCP Toolbox**.
